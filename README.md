# Agent Board

Локальна дошка «кімната команди» для всіх сесій [Claude Code](https://claude.com/claude-code): кожна розмова — картка-«співробітник» з проєктом, станом і коротким підсумком. Видно, хто чекає на вашу відповідь, хто працює, що закинуто, і до якого проєкту це належить.

- **Стани:** чекає на вас (зокрема питання / дозвіл), працює, чекає на фонові задачі, спить; «Готово» / «Відкласти» ховають картку, нова активність повертає її.
- **Проєкти:** за git-коренем першого `cwd` розмови, worktree — до головного репо; ваші проєкти «назва + тека» (панель «🗂 Проєкти») мають пріоритет; суміжні проєкти — за файлами й командами.
- **Підсумки:** ізольований `claude -p --model haiku` (без хуків, плагінів і MCP), ліміт на годину, backoff і запобіжник. Робоче (родини й теки з конфігу) у Haiku не відправляється.
- **Дві дошки з одного коду:** особиста (`~/.claude`) і робоча (окремий акаунт з `CLAUDE_CONFIG_DIR`, Haiku вимкнено примусово).
- **Перехід до розмови:** закрита — відкривається в Terminator на весь екран (ваш профіль, вкладки «назва картки» + «термінал»); жива — фокус вікна, де вона працює.
- **VS Code:** кнопка `</> VS Code` в панелі картки й у «Проєктах» відкриває теку проєкту (для worktree — саме його). Якщо VS Code не встановлено, кнопок немає.
- **Пошук** (`/`), чипи родин, панель звіту з Markdown, космічна тема зі склом.
- Linux і macOS; лише stdlib Python 3.11+, без обов’язкових залежностей; HTTP + SSE лише на `127.0.0.1` з перевіркою `Host` / `Origin`.

## Запуск

Потрібні Python 3.11+, `tmux` і Claude Code.

    cp config.example.toml config.toml     # і за потреби config.work.example.toml → config.work.toml
    ./agent-board start                    # у фоні: http://127.0.0.1:8091, лог у ~/.local/share/agent-board/
    ./agent-board open                     # запустити й відкрити
    ./agent-board stop | restart | status  # розмови в терміналах переживають зупинку дошки

Другий аргумент — інший конфіг: `./agent-board start config.work.toml`.

### Linux

`open` відкриває вікно-застосунок Chrome (`--app`), а вже відкрите виводить наперед (`wmctrl`). «Перейти» відкриває розмову в Terminator; якщо його немає, кнопку сховано й лишається термінал у картці. Автозапуск: systemd user-service (`agent-board.service`) або `run.sh` у `~/.config/autostart`.

### macOS

    brew install python tmux
    ./agent-board autostart                # LaunchAgent: запуск при вході
    ./agent-board open

Щоб мати окреме вікно й значок у Dock: у Chrome «Встановити сторінку як застосунок». Кнопки «Перейти» немає: розмови відкриваються в картці. Диктування (необов’язково): `python3 -m pip install faster-whisper` у той Python, яким запускається дошка, і завантажена модель; мікрофон вмикає Ctrl+Shift+Пробіл.

## Конфіг

`config.toml` (у git не потрапляє, зразок — `config.example.toml`): назва й значок дошки, `claude_dir`, порт, родини проєктів, теки без git, `summary_exclude_families` / `summary_exclude_paths`, ліміти Haiku, `planet` (`ringed` / `mars`). Локальні файли (наприклад, чужі логотипи для значка) — у `assets/local/`, теж поза git.

## Термінал у картці й диктування

Вкладка «Термінал» у панелі картки — справжній Claude Code. Він працює в окремому сервері tmux (`tmux -L agent-board-<порт>`), тому закрита картка чи перезапуск дошки його не зупиняють.

- **＋ Новий чат** — нова розмова в теці проєкту, яку дошка вже знає (або доданій у «Проєкти»).
- **Продовжити тут** — закрита розмова (`claude --resume`). **Забрати в дошку** — розмова, відкрита в іншому терміналі: Claude там отримує SIGTERM, і розмова продовжується тут.
- Поле під терміналом: Enter — надіслати, Shift+Enter — новий рядок. Поки Claude показує меню, текст не надсилається.
- **⌨ 12/12** у заголовку — скільки терміналів відкрито з ліміту; натискання показує лише ці картки, разом з архівом. Термінал картки «Готово» чи «Відкладено» закривається сам після 5 хв простою Claude (не поки картка відкрита у вікні); розмову можна продовжити. У конфігу: `max_terminals`, `close_archived_after` (секунди, 0 — не закривати).
- **Назва розмови** сама йде за темою картки (з другої репліки; далі — коли тема міняється). Назву, яку дали ви через `/rename`, дошка не чіпає. Працює лише для розмов, запущених з дошки: хук передається їм через `--settings`, ваш settings.json не змінюється. Вимкнути: `auto_title = false`.
- **🎤** або Ctrl+Пробіл — диктування через локальний faster-whisper; звук не пишеться на диск і не виходить у мережу. Рядок диктування з’являється, лише якщо під час запуску дошки знайдено faster-whisper і модель у кеші Hugging Face; інакше лишаються клавіатура й голосовий режим самого Claude Code. У конфігу: `dictation_model` (типово `small`), `dictation_threads`, `dictation_languages`.
- Потрібен `tmux`; для диктування (необов’язково) — `pip install faster-whisper` і завантажена модель. xterm.js (MIT) лежить у `web/vendor`.

## Теми

Список у шапці: два «космоси» і класичні схеми (Dracula, One Dark, Tokyo Night, Catppuccin, Nord, Gruvbox, Monokai, Solarized, GitHub, «Фосфор» та світлі). Тема фарбує і дошку, і термінал; вибір пам’ятає браузер, окремо для кожної дошки. Нова тема — один рядок у `web/themes.js`: кольори тексту самі підтягуються до контрасту 4.5:1.
